Ship of Theseus

Replace every plank. Is it the same ship?

If you replace every plank of a ship one by one, is it still the same ship? Every part starts in the original color. A replaced part changes color.

Each single replacement feels too small to matter.

After all planks are new, nothing of the original remains.

The question is where (or whether) it stopped being the same ship.
