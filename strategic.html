Strategic voting

You want A to win. C is ahead. Your one vote is still blank.

You want A to win. Your real order is A first, B second, and C last. C is the one you want to lose.

Other people have already voted. C has 3 first places, B has 2, and A has 1, so C is ahead. Your ballot is the blank page. It is not in those stacks yet.

Add your one vote. A vote for A is the honest vote. A vote for B uses your second choice. Then see whether C still wins.

Before your vote, C has 3, B has 2, and A has 1. You want A, and C is ahead.

A vote for A makes the totals A 2, B 2, C 3. C still wins. A vote for B makes the totals A 1, B 3, C 3. B catches C, so C no longer wins alone.

The vote that stops your last choice is your second choice, not the one you want most.
